HOW TO UPDATE THE EXISTING GITHUB REPOSITORY
  1. Unzip this package.
  2. Open the EXTRACTED FOLDER and select ALL its contents, including the
     four HTML pages, styles.css, script.js, CNAME and the assets folder.
  3. Copy these contents into the root of your local Website repository.
     Do NOT put the whole folder INSIDE the repository as a subfolder.
  4. Replace existing files when prompted.
  5. Commit and push in GitHub Desktop (or upload through GitHub web).
  6. Verify Settings > Pages still lists www.asratatsedeweyn.com.
  7. After deployment, test Home, Leadership, Research and Contact on desktop/mobile.
